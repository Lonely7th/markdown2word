## ✨ 简介

**Markdown2Word** 是一款强大的文档格式转换工具，致力于解决 Markdown 文档导出为办公格式时的格式错乱问题。

无论是开发者编写的技术文档，还是用户使用 **DeepSeek、ChatGPT、豆包、千问** 等 AI 生成的长篇内容，Markdown2Word 都能将其完美转换为 **Word (.docx)**、**PDF** 或 **Excel (.xlsx)** 文档。

### 🚀 核心优势

- **📄 完美格式保留**：智能还原标题层级、字体样式、列表缩进，无需二次排版。
- **🧮 LaTeX 公式支持**：自动识别 LaTeX 数学公式并转换为 Word 原生公式对象（OMML），双击可编辑，告别图片乱码。
- **📊 Mermaid 图表渲染**：支持流程图、序列图、甘特图等复杂图表的渲染与导出。
- **🤖 AI 内容深度适配**：针对 AI 生成的大量 Markdown 内容（代码块、复杂表格）进行了专项优化。

## ❓ 常见问题解答 (FAQ)

<details>
<summary><b>如何在线将 Markdown 转换为 Word 文档？</b></summary>
<br>

使用 Markdown2Word 进行转换非常简单。首先，将您的 Markdown 内容复制到剪贴板，或者准备好 .md 文件。然后，打开我们的在线转换工具，粘贴文本或上传文件，选择输出格式为 Word (.docx)，点击“开始转换”即可。整个过程免费且无需安装任何软件。

</details>

<details>
<summary><b>Markdown 转 Word 工具是免费的吗？</b></summary>
<br>

是的，Markdown2Word 的基础在线转换功能完全免费。您可以进行无限制的 Markdown 转 Word 和 PDF 操作。对于有高级需求的用户（如本地批量处理、API集成等），我们也提供付费的专业版插件和桌面客户端。

</details>

<details>
<summary><b>转换工具支持 LaTeX 数学公式吗？会出现乱码吗？</b></summary>
<br>

这是我们核心优势之一。Markdown2Word 完美支持 LaTeX 数学公式转换。我们会将 LaTeX 语法（如 $E=mc^2$）智能解析并转换为 Word 原生的 OMML 公式对象，这意味着转换后的公式在 Word 中是可以直接编辑的，绝不会出现图片乱码或模糊的问题。

</details>

<details>
<summary><b>为什么我的 Markdown 表格转换到 Word 后错位了？</b></summary>
<br>

这种情况通常是因为源 Markdown 的表格语法不够标准。Markdown2Word 内置了“智能表格修复”算法，能自动对齐列宽。如果仍有问题，请确保源文本中使用标准的 `|` 分隔符，或者尝试使用我们的“Markdown 转 Excel”功能，提取表格数据后再粘贴回 Word。

</details>

<details>
<summary><b>除了 Word，还支持导出 PDF 和 Excel 吗？</b></summary>
<br>

支持。Markdown2Word 是一款全能的转换工具。您可以将 Markdown 导出为高清 PDF 文档（适合打印和归档），也可以将其中的表格数据提取并导出为 Excel (.xlsx) 文件。在插件和桌面版中，您甚至可以一键同时导出这三种格式。

</details>

网页版目前支持单文件转换。如果您需要批量处理大量 Markdown 文件（例如将整个电子书项目转换），建议下载我们的桌面客户端或安装浏览器插件。这些版本支持文件夹拖拽批量转换，能极大提高您的工作效率。
