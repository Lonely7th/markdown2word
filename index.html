常见问题

使用 Markdown2Word 前需要了解的信息。

Markdown2Word 和 MD2Word 是什么？

它们都指向本站提供的 Markdown 转 Word 工具。Markdown2Word 是站点品牌，MD2Word 是常见简写。

转换后的 Word 可以继续编辑吗？

输出为标准 DOCX 文件，可使用 Microsoft Word 或 WPS 打开并继续编辑。复杂文档在正式交付前仍建议进行一次复核。

支持 PDF 吗？

支持。Word 是本站的主要输出格式，PDF 作为附加格式，可以在工具顶部切换。

为什么转换时需要登录和VIP？

文档解析、公式处理和文件生成会使用服务器资源。登录用于确认账号，VIP用于获得完整的 Word 与 PDF 转换能力。

我的 Markdown 会保存在网站吗？

本站不提供历史记录并默认使用无痕参数，但内容必须发送到转换服务器才能生成文件。请参阅隐私说明了解数据处理边界。
