常见问题

使用 AI文档解析前需要了解的信息

AI文档解析是什么？

AI文档解析是一款把 AI 生成的 Markdown 内容转换为 Word 或 PDF 的在线工具，适合整理问答、报告、论文草稿与技术文档。

支持哪些 AI 平台生成的内容？

支持 DeepSeek、豆包、ChatGPT、Claude 等平台输出的 Markdown。只要内容使用标准 Markdown 或常见扩展语法，均可粘贴或上传转换。

它和普通 Markdown 转 Word 工具有何不同？

除标题、列表和简单表格外，本站还重点处理完整 LaTeX 上下文、表格内公式、SVG、Mermaid 和复杂嵌套内容，尤其适合 AI 生成的长文与技术内容。

转换后的 Word 可以继续编辑吗？

输出为标准 DOCX 文件，可使用 Microsoft Word 或 WPS 打开并继续编辑。复杂文档在正式交付前仍建议进行一次复核。

支持 PDF 吗？

支持。Word 是本站的主要输出格式，PDF 作为附加格式，可以在工具顶部切换。

为什么转换时需要登录和VIP？

文档解析、公式处理和文件生成会使用服务器资源。登录用于确认账号，VIP用于获得完整的 Word 与 PDF 转换能力。

转换时会提交哪些内容？

点击转换后，Markdown 内容和转换选项会发送至转换服务器，用于生成 Word 或 PDF。请参阅隐私说明了解数据处理边界。
