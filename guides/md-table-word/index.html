MD 转 Word 后表格错位怎么办？

大多数问题发生在源 Markdown 的结构、单元格内容和 Word 页面宽度之间。先从源文档规范化开始。

使用标准的 Markdown 表格结构

每张表都应该有表头、分隔行和一致的列数。不要混用竖线、制表符和手工空格来“对齐”内容；视觉对齐应由渲染器和 Word 样式负责。

避免把复杂布局塞进表格

长段落、嵌套列表、多张图片和代码块会让单元格高度与宽度难以控制。可将说明文字移到表格外部，或拆成两张更聚焦的表。

导出后的检查顺序

  1. 检查表格是否超出页面左右边距。
  2. 确认每一页的表头、换行与断页是否可读。
  3. 检查列内的图片、链接和特殊字符是否完整。
  4. 若收件人使用 WPS 或 Google Docs，额外打开复核一次。
