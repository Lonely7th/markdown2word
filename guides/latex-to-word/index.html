LaTeX 公式怎样转到 Word？

公式是否需要继续编辑、目标读者使用什么软件，以及排版精度要求，决定了最合适的导出方式。

先确定“可编辑”是否必要

如果收件人需要在 Word 中修改公式，优先选择能生成 Word 公式对象的转换能力；若只要求视觉呈现稳定，公式图像也是可选方案。两者在兼容性和后续编辑成本上不同。

Markdown 中的公式写法

行内公式与独立公式应保持明确边界，避免在公式中混入未转义的特殊字符。对编号、引用、矩阵和长公式，应在导出后检查换行与对齐。

交付前检查

  • 在 Microsoft Word 或实际收件人使用的软件中打开文档。
  • 确认公式没有被替换为乱码、空白或低清图片。
  • 检查长公式、上下标和分式在分页位置是否正确。
  • 保留 Markdown 原文，便于后续修订和再次导出。
论文、实验报告与正式技术文档建议使用完整转换流程，并留出人工复核时间。
