如何高保真进入 Word？

SVG 能在缩放时保持清晰，但网络资源、内联代码和不同办公软件的支持差异，会让普通转换流程出现缺图或模糊。

为什么 SVG 比普通图片更难处理

PNG 和 JPEG 通常可以直接嵌入，而 SVG 可能来自网络链接、Data URI、HTML 内联片段或相对路径。转换器需要先定位资源，再根据 DOCX 与目标软件的兼容性选择合适的嵌入方式。

转换前保留完整引用

  • 不要提前把 SVG 标签删除或替换成文件名。
  • 网络 SVG 应确保转换服务可以访问。
  • 相对路径资源需要与源文档保持明确关系。
  • 包含字体、滤镜或外部样式的 SVG，应在导出后重点复核。

高保真并不等于无需复核

矢量资源的目标是保持清晰度与结构完整。不同版本的 Word、WPS 和 Google Docs 对 SVG 的显示能力不同，正式交付前应在收件人使用的软件中打开检查。
